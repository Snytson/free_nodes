# GeoLite2 Country database

Local MMDB used by the catalog's offline country classifier.

Source distribution: https://github.com/wp-statistics/GeoLite2-Country
CDN: https://cdn.jsdelivr.net/npm/geolite2-country/GeoLite2-Country.mmdb.gz

The distribution states that this is a GeoLite2 Country database derived from
MaxMind data. Review the current MaxMind GeoLite2 license/EULA and the
distributor's terms before redistribution.
